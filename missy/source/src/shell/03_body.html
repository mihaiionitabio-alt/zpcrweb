Or paste Cq values from any instrument

A pasted table can be tidied and downloaded again, but it carries no fluorescence, so the curve-based exports need an .ixo file. Paste or upload a table with a sample column and a Cq column — the header names are matched loosely, so exports from most instruments work as they are. A well column is used if present.
