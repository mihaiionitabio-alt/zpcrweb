# MISSY

MISSY is a free, open-source application for reviewing real-time PCR data, delivered as a single, unencrypted HTML file. Save the file and use it offline. Experiment processing occurs locally. Optional offline speech recognition requires a compatible browser and an initial language-pack download.

**Research use only. MISSY is not validated.** Software checks in this wiki do not establish diagnostic performance, accreditation or fitness for a laboratory's intended use.

Current documentation baseline: **2026.10.31.demolabels1**, commit `e8d8198d62cc4ac1470a4a9d034c14ff1e2c7ac4`.

## Capabilities

- Read IXO, EDS, EDT, RDML, ZPCR and PCRD files within documented reader constraints, including ZIP intake.
- Inspect amplification curves, stored threshold-cycle, melting and quantity results where supplied.
- Review controls and replicates under the selected laboratory SOP.
- Explore control charts, drift, outliers and missing same-channel results.
- Use English or Chinese interfaces, mouse, keyboard and optional voice commands.
- Practise with two artificial-data demonstrations and a guided learning game.
- Export evidence and reports with their applicable provenance and limitations.
