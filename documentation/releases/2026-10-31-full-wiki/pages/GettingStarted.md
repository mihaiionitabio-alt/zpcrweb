# Getting started

1. Download the current HTML and open it in a supported modern browser.
2. Select the interface language and enter laboratory and investigator details. These fields identify the session; they are not authentication.
3. Choose **Real data analysis** or **Learning game**. The learning workspace loads artificial data and must not be confused with laboratory results.
4. Stage files, read them, and review the file summary before interpreting results.
5. Select or configure an approved laboratory SOP, review applicability and controls, and examine the evidence behind flags.
6. Export the report for that analysis and retain the build and profile identities with the original files.

Internet Explorer is unsupported. Optional offline speech recognition has narrower browser support than the core page. Browser capability messages must be followed; a Chinese interface does not install a Chinese speech voice.
