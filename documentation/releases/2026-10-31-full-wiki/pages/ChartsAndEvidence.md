# Charts and evidence

The current registry contains **83 control-chart definitions** and **25 single-run graph definitions**. These counts describe available definitions; each input file may support only some of them.

Read the plotted quantity, channel, run/acquisition scope, units, baseline minimum and limits before interpreting a point. A chart without sufficient baseline or declared limits cannot be called a pass merely because no point is flagged.

Review amplification, plate/sample associations, instrument records, stored results and rising curves without a same-channel result. A flag describes an observed rule violation, not its biological or hardware cause.

Default dark charts and optional white backgrounds support screen review. Numbered voice chart requests use the focused Console view with a way to restore headers and controls.
