# Full-page workspace entry and learning preparation

Build 2026.10.29.learning4 replaces the small workspace dialog with a full-screen LCARS selection page. Large Learning game and Real data analysis cards use the existing MISSY logo, lavender rails, orange headings and original inline DNA/amplification SVG graphics. Separate English/Chinese copy, keyboard navigation, back-to-session control and a local sound toggle are provided. Selection cues are original Web Audio oscillator tones; no external or franchise recordings are used.

Learning mode now hides the entire workspace header, iframe and guide until the owned child document is decoded, profiled, initialised, font-ready and painted. The black/orange/lavender preparation screen shows a stage progress bar, live elapsed milliseconds and a timestamped stage log. Progress represents five actual preparation stages, not a claimed byte percentage. The final measured duration is shown beside the first lesson heading.

Return/cancel takes the player back to workspace selection. Failed preparation stays hidden and offers retry/return. Ownership guards prevent a cancelled child from revealing or replacing a newer workspace. Real data analysis opens the existing normal workspace directly.

Tests cover both destinations and languages; desktop widths 1280/1536/1920; 1366x768 layout; keyboard arrows; non-silent/non-clipping local cue synthesis; hidden initial state; all five measured stages; ready data counts (33 runs, 789 records); cancel/failure/retry; and separate-format scientific/export parity. PCRD coverage is the locked/cancel path; no decrypted PCRD claim. Existing readers, calculations, exports, font coverage and training report implementation are unchanged.
